How the Action attribute works

... in my own words

The action attribute is an intergral part of the form attribute. It determines where the form data is submitted. It determines the general destination of any data that is submitted into this form. The url / destination assigned to the attribute determines the where the submitted data is stored via server. The servers are typically ran on secure network which allow for the backend to access and generally process the data that was submitted
In simplier terms, the action attribute is used to assign a url /destination for the inputted data in the form to be stored in.
